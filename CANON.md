# quilt-bridge

**What this repo is**: canon crosses substrates via translation.

Substrate transition in 24 lines.

- lore text → Python dict / SQL / Rust / TypeScript
- same lore, four substrates, byte-different but semantically same
- the **polyformalism substrate walker** loads canon in the language
  it needs

When the substrate walker wants to speak SQL, it gets SQL. When it
wants to speak Rust, it gets Rust. Same canary, different substrate.
